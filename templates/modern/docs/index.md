## How this documentation stays current

The [`doctyze-review` GitHub Action](../.github/workflows/doctyze-review.yml)
runs on every PR. If your change touches behavior the docs describe,
the bot will suggest doc updates inline — and depending on enforcement
mode, can block merge until they're addressed.
