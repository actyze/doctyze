# Code of Conduct

This project adopts the **[Contributor Covenant Code of Conduct,
version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**
in full. By participating in the Doctyze community, you agree to abide by it.

## Our pledge

We are committed to a welcoming, inclusive, and respectful community for
everyone — regardless of experience level, background, or identity. The
Contributor Covenant captures this commitment precisely; we adopt it
rather than rewrite it.

The full text is available at
**https://www.contributor-covenant.org/version/2/1/code_of_conduct/**.

## Scope

This Code of Conduct applies to all project spaces:

- The `actyze/doctyze` GitHub repository (issues, PRs, discussions,
  reviews, commit messages)
- Any official communication channels (Discord, Slack, mailing lists)
- Community events and meetups organized under the project name
- When an individual is officially representing the project in public

## Reporting

If you experience or witness behavior that conflicts with this Code of
Conduct, please report it to **conduct@actyze.com**. Reports go directly
to the project maintainers and are handled confidentially.

What to include in a report (all optional):

- A description of what happened, with enough context to understand it
- When and where it occurred (issue / PR / discussion link is ideal)
- Any other relevant information
- Whether you'd like a follow-up

Reports are reviewed within 7 days. We will not name the reporter without
their consent.

## Enforcement

The project maintainers are responsible for clarifying and enforcing
this Code of Conduct. Consequences for violations follow the Contributor
Covenant's standard enforcement ladder (correction → warning →
temporary ban → permanent ban) as judged appropriate by the maintainers.
